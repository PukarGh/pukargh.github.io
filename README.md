# pukargh.github.io

The source for my personal portfolio site, hosted on GitHub Pages.

## The problem it solves

A résumé file is easy to lose and hard to keep current. This site gives a single, always-available link that introduces who I am, my professional experience, and the projects I've worked on.

## What's on the site

- A short introduction and research interests
- Professional experience timeline
- Selected projects

## Tech

Plain HTML, CSS, and JavaScript, with no framework and no build step.

```
index.html     # Page content
css/index.css  # Styles
js/index.js    # Script hook (currently empty)
images/        # Assets
```

## Running locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Deployment

Any push to `main` is published automatically by GitHub Pages at https://pukargh.github.io.
